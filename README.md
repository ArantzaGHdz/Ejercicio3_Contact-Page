## 📝 Reflexión

Aprendí a utilizar más tipos de forms como dropdown y textarea para que los usuarios puedan seleccionar o escribir información. Además de aplicarles un diseño personalizado con flex para alinearlos de acuerdo a ciertas orientaciones.

Tuve unas dos complicaciones al realizar este ejercicio: primeramente, los 4 campos de input (Name y Company Email) y dropdown (Company Size y Subjet) no se alineaban correctamente horizontalmente, puede resolverlo al modificar el atributo flex de los input (.input-text, .input-dropdown) como flex: 1, en vez de un valor automático que se calcula en base al tamaño del contenido (original: flex: 1 1 auto). La segunda complicación fue cuando al modificar el diseño para adaptarlo a la pantalla de celular, la imagen de fondo mantenia su tamaño y por consiguiente se veía un recortado en la parte de abajo; pude resolver esto al investigar en internet y aplicar la propiedad de background-attachment: fixed, usada para renderizar imagenes en el dispositivos móviles.
